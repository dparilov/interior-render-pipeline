- Скетч может иметь голубой пол, белую ванну, голубые стены

- Нужен умный сегментатор, а не цветовой маппинг

**Что уже работает:**
- ✅ Canny ControlNet сохраняет структуру скетча

```
Скетч → Canny ControlNet → Базовая генерация
                ↓
```

### 🔴 КРИТИЧЕСКИЙ БАГО — Неконсистентная верификация

**Проблема:** Я менял критерии верификации между v5 и v6:
- v5: "Покрывает ли маска объект?" — scores 92-97%
- v6: "Соответствует ли цвет ожидаемому?" — scores 30-68%

Это яблоки с апельсинами! Нельзя сравнивать.

**Зафиксированный единый принцип:**

Верифицируем ЗОНЫ, не цвета:
- **Coverage** — % площади объекта покрытый маской (0-100%)
- **Precision** — маска не залезает на соседние объекты (0-100%)
- **Confidence** = (Coverage + Precision) / 2
- **Порог:** 95% для перехода к следующему этапу

Цвета в seg_map НЕ важны — они только определяют границы. IP-Adapter применит правильную текстуру.

## Scene Bundle Architecture (17:12-19:10)

### Новый подход к rendering pipeline

**Проблема:** Сегментация из растра (UperNet/SAM) даёт 76% avg confidence — много "угадывания".

**Решение:** Инверсия источника истины — получать структуру сцены из SketchUp модели, а не восстанавливать из картинки.

### Архитектура

```
ТЗ + SKP → AI понимает сцену → Scene Bundle → Рендер с authoritative данными
```

**Scene Bundle содержит:**
- `manifest.json` — метаданные, версия
- `geometry/scene_graph.json` — полный граф с классификацией
- `views/` — рендеры с разных ракурсов (beauty, shell, surfaces, fixtures)
- `masks/` — бинарные маски каждого элемента
- `entities/` — детали по каждой сущности

### Классификация сущностей

| Тип | Примеры |
|-----|---------|
| structure | стены, пол, потолок |
| surface | плитка, краска (на structure) |
| fixture | мебель, сантехника |
| opening | окна, двери |

### Scene Extractor Plugin

**Файл:** `~/.openclaw/workspace/projects/interior-render/sketchup/scene_extractor.rb`

Ruby plugin для SketchUp:
- Обходит все entities (группы, компоненты, faces)
- Извлекает: persistent_id, имена, материалы, bounds, атрибуты
- Экспортирует scenes/cameras
- Дампит в JSON

**Команды:**
```ruby
load '/path/to/scene_extractor.rb'
SceneExtractor.summary
SceneExtractor.extract_to_file('/path/to/scene_graph.json')
```

## Bundle Render v7 — новый скрипт (21:25-22:06)

### comfyui-render-bundle.py

**Файл:** `~/.openclaw/workspace/ops/comfyui-render-bundle.py`

**Ключевое отличие от comfyui-render.py:**
- Читает `bundle_manifest.json` напрямую
- **NO UperNet/SAM** — использует только authoritative маски из SketchUp
- `IPAdapterAdvanced` с `attn_mask` для каждого entity
- `LoadImageMask` (не LoadImage!) для масок — возвращает MASK тип

### Архитектура workflow

```
checkpoint → ipadapter_basket (mask) → ipadapter_bathtub (mask) → ... → sampler
             ↓                         ↓
          basket.jpg              bathtub.jpg
          mask_basket.png         mask_bathtub.png
```

### Баг: attn_mask требует MASK тип

**Ошибка:** HTTP 400 при отправке workflow.
**Причина:** `LoadImage` возвращает IMAGE, а `IPAdapterAdvanced.attn_mask` ожидает MASK.
**Решение:** Заменить `LoadImage` на `LoadImageMask` с `channel: "red"`.

### Успешный запуск

```bash
python3 comfyui-render-bundle.py --bundle ~/ComfyUI/input/bathroom_masha/bundle_manifest.json --steps 20 --output bathroom_v7_sketchup
```

## Диагностика провала v7 (22:30-23:04)

### Ошибка #1: CLIP Vision несовпадение
```
size mismatch for proj_in.weight: 
  checkpoint: torch.Size([1280, 1280])
  model expects: torch.Size([1280, 1664])
```
**Причина:** `ip-adapter-plus_sdxl_vit-h.safetensors` требует `CLIP-ViT-H-14`, а скрипт использовал `CLIP-ViT-bigG-14-laion2B`.
**Исправлено:** Заменил CLIP Vision на `CLIP-ViT-H-14-laion2B-s32B-b79K.safetensors`.

### Ошибка #2: Разрешение sketch ≠ маски
- Sketch: **1280×720** (скопирован вручную откуда-то)
- Маски: **1920×1080** (экспортированы скриптом)

**Результат:** IP-Adapter применял маски на неправильные области (масштаб не совпадал).

### Ошибка #3: Маски были пустые (0%)
Zip архив распаковался в подпапку `masks_sketchup/masks/`, а скрипт искал в `masks_sketchup/`.
**Исправлено:** `mv masks/*.png .`

### Ошибка #4: КРИТИЧЕСКАЯ — маски без окклюзии
**Vision верификация показала:**
- Маска `walls` (30% coverage) покрывает ВСЁ: стены + vanity + mirror + bathtub + basket
- Это потому что SketchUp hide_all → show_walls рендерит геометрию стен БЕЗ учёта объектов перед ними
- Ожидаемая точность: **35-45%** вместо ~100%

**Решение:** Переписать экспорт масок с учётом окклюзии:
1. Показать ВСЁ
2. Целевой объект → белый
3. ВСЕ ОСТАЛЬНЫЕ объекты → чёрный (включая те что перед целевым)
4. Рендер — объекты впереди "вырежут" дырки

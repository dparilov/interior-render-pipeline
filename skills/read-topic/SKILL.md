# read-topic

Чтение истории Telegram топика через Pyrogram userbot.

## Когда использовать

- При старте сессии в топике Telegram группы — для восстановления контекста
- По команде "перечитай контекст" — читай СВОЙ топик
- По команде "перечитай топик X" — читай указанный топик

## Правила

⛔ **ЗАПРЕЩЕНО:**
- Писать свой код — используй ТОЛЬКО готовый скрипт
- Устанавливать пакеты (`pip install`)
- Модифицировать `read-topic.py`

✅ **РАЗРЕШЕНО:**
- Вызывать готовый скрипт
- Указывать chat_id, topic_id, limit

## Использование

```bash
python3 ~/.openclaw/workspace/ops/read-topic.py <chat_id> <topic_id> [limit]
```

### Параметры

- `chat_id` — ID чата (со знаком минус для групп)
- `topic_id` — ID топика (0 для General или чата без топиков)  
- `limit` — количество сообщений (по умолчанию 5000)

### Варианты команд от пользователя

| Команда | Действие |
|---------|----------|
| "перечитай контекст" | Свой топик, limit=5000 |
| "перечитай последние 100 сообщений" | Свой топик, limit=100 |
| "перечитай топик Voice AI" | Топик 406, limit=5000 |
| "покажи что было с 24 марта" | Свой топик, limit=5000, потом фильтруй по дате в выводе |

## Известные чаты

| Chat ID | Название | Топики |
|---------|----------|--------|
| `-1003596522926` | Clearmind_projects | 0=General, 406=Voice AI, 391=Assistant, 508=Transcripts, 1303=Pepper Potts, 60=HomeDocs |
| `-1003888103563` | AI T1 pptx test (GenAI) | 0=General |

## Примеры

```bash
# Voice AI топик (полный)
python3 ~/.openclaw/workspace/ops/read-topic.py -1003596522926 406 5000

# Assistant топик  
python3 ~/.openclaw/workspace/ops/read-topic.py -1003596522926 391 5000

# GenAI чат (General)
python3 ~/.openclaw/workspace/ops/read-topic.py -1003888103563 0 5000

# Последние 200 сообщений
python3 ~/.openclaw/workspace/ops/read-topic.py -1003596522926 406 200
```

## Определение своего топика

Из inbound context агент получает `chat_id` и `topic_id`. Используй их для чтения СВОЕГО топика:

- Если `chat_id = -1003596522926` и `topic_id = 406` → Voice AI
- Если `chat_id = -1003596522926` и `topic_id = 391` → Assistant (Алёна)
- Если `chat_id = -1003888103563` → GenAI

## Изоляция контекста

**ВАЖНО:** Каждый топик = отдельный контекст.

- НЕ читай топики, в которых тебя не вызвали
- НЕ упоминай информацию из других топиков без явного запроса
- Детали топика A не должны попадать в топик B

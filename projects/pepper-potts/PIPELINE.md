## Phase A: Классификация interactions

**[A.1]** Use cases из реальных логов 🔲
- 5-10 транскриптов из `logs/` с ожидаемым выводом
- task / idea / question / conversation

**[A.2]** Промпт для Opus + структура JSON 🔲
```json
{
  "intents": ["task|idea|question|conversation"],
  "entities": {"people": [], "places": [], "dates": [], "topics": []},
  "action_items": []
}
```
- Итеративная отладка на реальных примерах

**[A.3]** Написать `ops/classify-interactions.py` 🔲
- Инкремент из `interactions.md` → Opus → `tasks.md` / `ideas.md` / `daily/YYYY-MM-DD.md`

**[A.4]** Cron для classify-interactions 🔲
- Каждые 10-30 мин, только если есть новые записи, no-deliver

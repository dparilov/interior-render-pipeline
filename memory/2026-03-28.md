## Windows VM — Полностью настроена! ✅

**Статус на 17:08:**
- Windows 11 Enterprise Evaluation установлена
- User: `dmitrii`, Password: `dmitrii`
- UEFI boot (OVMF) — работает

**Конфигурация QEMU:**
```bash
qemu-system-x86_64 \
  -machine q35,accel=kvm \
  -cpu host -m 8192 -smp 4 \
  -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE_4M.fd \
  -drive if=pflash,format=raw,file=~/vm-setup/sketchup_VARS.fd \
  -drive file=~/vm-setup/sketchup.qcow2,format=qcow2,if=virtio \
  -netdev user,id=n0,hostfwd=tcp::3389-:3389,hostfwd=tcp::2222-:22 \
  -device virtio-net-pci,netdev=n0 \
  -vnc 0.0.0.0:0 \
  -daemonize
```

**Port Forwarding:**
- VNC: `localhost:5900` → VM display
- RDP: `localhost:3389` → VM RDP (нужно включить в Windows)
- SSH: `localhost:2222` → VM SSH (нужно включить в Windows)

**Tailscale доступ:**
- VNC: `100.96.1.25:5900`
- RDP: `100.96.1.25:3389`
- noVNC: `http://100.96.1.25:6080/vnc.html`

**Проблемы vncdotool:**
- Символ `:` заменяется на `;` или `-`
- Двойные клики не работают
- Кавычки `"` заменяются на `'`
- **Решение:** Нужно RDP или SSH для нормального управления

**Следующий шаг:**
Дмитрий должен зайти в noVNC и выполнить команду:
```
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections /t REG_DWORD /d 0 /f
```
После этого RDP будет работать и можно автоматизировать через SSH/RDP.

**HTTP сервер для файлов:**

## Windows VM — SSH + RDP работают! ✅ (18:22)

**Ключевое решение: e1000 вместо virtio-net**
- Windows не имеет драйверов VirtIO для сети по умолчанию
- Переключили на e1000 — сеть заработала!

**Доступы:**
```bash
# SSH (работает)
ssh dmitrii@localhost -p 2222

# RDP (работает)
xfreerdp /v:localhost:3389 /u:dmitrii /p:dmitrii /cert:ignore +clipboard

# VNC (работает)
vncdo -s localhost::5900 capture screenshot.png
```

**SSH ключи для админов:**
- Ключ должен быть в `C:\ProgramData\ssh\administrators_authorized_keys`
- НЕ в `C:\Users\dmitrii\.ssh\authorized_keys` (не работает для админов)

**xdotool + xclip для RDP автоматизации:**
```bash
# Найти окно
WIN_ID=$(xdotool search --name "FreeRDP" | head -1)
# Скопировать команду
echo -n 'Get-Process' | xclip -selection clipboard
# Вставить и выполнить
xdotool windowactivate $WIN_ID && xdotool key ctrl+v && xdotool key Return
```

- Скрипт скопирован в Plugins для автозагрузки: `C:\Users\dmitrii\AppData\Roaming\SketchUp\SketchUp 2026\SketchUp\Plugins\`

- **8/10 объектов** найдено (walls, floor — NOT FOUND, это EMPTY без mesh в GLB)

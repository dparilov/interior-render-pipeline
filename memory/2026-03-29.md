## Geometry Control — Strict Positioning (12:21 - 12:31)

### Проблемы первого рендера (Opus Vision верификация)

| Проблема | Где | Критичность |
|----------|-----|-------------|
| Душ появился СЛЕВА | Левая стена | 🔴 Критично |
| Уступ/ступенька справа | Правая стена у ванны | 🔴 Критично |
| Левая стена сплошная | Вместо проёма | 🟡 Средне |
| Лишние полотенца | По всему кадру | 🟡 Средне |
| Выход за границы сцены | Модель "додумала" объекты | 🔴 Критично |

### Причина

- Canny ControlNet видит только края, не понимает 3D
- DepthAnything генерирует depth из картинки — угадывает
- Модель "додумывает" геометрию в пустых зонах

### Решение: Ground Truth из SketchUp

Добавлено в `irp_export.rb`:

1. **`depth.png`** — Depth map из реальной геометрии
   - `paint_by_depth()` — красит faces по расстоянию от камеры
   - Ближе = белее, дальше = темнее
   - Ground truth, не нейросетевое угадывание

2. **`boundary_mask.png`** — Силуэт комнаты
   - Вся комната (все mapped entities) = белый
   - За пределами = чёрный
   - Использовать как `latent_mask` в KSampler

### Обновлённый Workflow

```
SketchUp depth.png → ControlNet Depth (0.9, more_control)
SketchUp boundary_mask.png → SetLatentNoiseMask
Canny 0.8, end 0.9
Negative: универсальный (без сцено-специфичных объектов)
```

### Универсальный Negative Prompt

```
"cartoon, anime, drawing, sketch, painting, illustration, CGI, low quality, blurry, distorted, watermark, text, objects not in reference image, extra fixtures, additional decorations, items not present in original, architectural elements not in source, modified wall structure, added ledges, steps, shelves, extra towels, human figure, person, mannequin"
```

### IPAdapter Pipeline Explanation

Каждый IPAdapter node делает:
1. CLIP Vision encode — reference image → embeddings
2. Image projection — 1280 dim → 8192 dim
3. Attention mask setup из бинарной маски
4. Model patching — модифицирует attention layers

На CPU: ~10-20 сек на encode × 10 images = 2-3 мин только encode
